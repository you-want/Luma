Luma v0.4.0 带来更完整的文件夹整理流程，并统一空间分析与文件管理的操作入口。

- **文件夹整理**：支持桌面与下载细分类、按文件类型或日期整理，以及文件名关键词规则。先预览再移动，可排除文件、修改分类和文件去向，同名文件支持跳过或自动编号；移动记录支持重启后撤销。
- **统一目录工作区**：当前目录、桌面/下载快捷入口和扫描操作固定在顶部，下方切换空间分析与文件管理。切换视图保留子目录和滚动位置，更换目录后提示重新扫描。
- **更顺畅的操作反馈**：文件与数据库任务在后台执行；耗时按钮显示等待状态并防止重复提交。修复重命名失焦吞掉其他按钮首次点击的问题。
- **文件预览与界面**：支持本地图片、文本及 PDF 首页预览；统一工具栏、目录树、列表与网格间距，调整小窗口预览和中英文布局，撤销使用明确的图标与文字。

普通扫描只读取文件元数据，文件操作由用户主动触发。规则整理默认保留已有子文件夹与隐藏文件，不覆盖同名目标。

下载：macOS 用户选择 `.dmg`（同时支持 Apple Silicon 和 Intel）；Windows x64 用户选择 `-setup.exe` 或 `.msi`。已安装 Luma 的用户也可通过应用内检查更新安装。

macOS 与 Windows 安装包附带 updater 签名，尚未启用平台代码签名或公证。Windows 真机安装、权限及跨版本升级回归仍待完成。
