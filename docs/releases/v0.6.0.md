Luma v0.6.0 重新梳理了应用的导航与信息架构，让「看清 → 管理 → 归位」的路径更短。

## 全新导航：工作区 / 全机 / 系统

- **侧边栏信息架构重组**：按「工作区（总览 / 空间分析 / 文件管理 / 整理）→ 全机（磁盘管家 / 会话）→ 系统（操作记录 / 设置）」三组九项重新排布，目录级操作与整机视角不再混在一层里。
- **总览仪表盘**：进入应用即看到「待整理、可复查的清理空间、重复文件」三个入口卡片与最近操作、扫描摘要，从待办直达对应页签。
- **统一操作记录**：整理、文件操作、清理与会话删除集中到「操作记录」一处，按类别筛选，状态（已完成 / 部分完成 / 已撤销 / 失败）与可撤销提示一目了然；重启后撤销记录保留。
- **顶栏更清爽**：隐藏文件开关、界面语言、更新入口收敛到「设置」页；顶栏只保留目录、重新扫描与本地存储。
- **品牌区**：侧边栏 logo 与名称、标语重新排布，小窗口自动折叠为图标栏。

## 界面与交互修复

- 会话页全选栏、分组头与会话行的勾选框对齐到同一条参考线，「删除所选」固定右侧。
- 整理页在规则卡片超出视口时可正常滚动（此前内容会被裁剪）。
- 扫描摘要、空间分析、文件管理在各窗口尺寸下的间距与对齐统一。

## 内部改进

- 前端拆分为 scan 生命周期 / 扫描动作 / 顶栏 / 分析面板，组件按功能域归目录；`invoke` 收敛到领域化 IPC 模块；Rust 命令层按领域拆分子模块。
- 浏览器回归统一迁移到 Playwright e2e（39 项，覆盖每个视图与整理全流程），退役依赖旧 DOM 的 Python 脚本；打包只携带使用到的设计 token。

安全边界与既有版本一致：删除只经废纸篓、绝不永久删除；写操作显式确认、执行前复核、白名单 fail-closed、操作全程留痕。

## 升级说明

已有用户可通过应用内检查更新安装；首次安装请选择 macOS `.dmg` 或 Windows x64 `-setup.exe` / `.msi`。本地数据库自动兼容升级，扫描索引与撤销记录保留；平台代码签名、公证与完整 Windows 真机回归仍待完成。
