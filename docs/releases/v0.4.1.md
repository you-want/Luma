Luma v0.4.1 优化本地存储占用、文件移动确认与 macOS 安装体验。

- **更清晰的 macOS 安装界面**：品牌背景、大图标和拖拽指引，窗口与内容对齐，支持 Apple Silicon 与 Intel。
- **本地存储管理**：查看索引及临时日志占用，回收空闲空间，或确认后清理扫描索引；原文件与撤销记录保留。
- **控制索引增长**：仅保留最近一次成功扫描的完整文件索引，历史转为统计摘要；每目录最多三次、全局最多三十次记录。单次扫描新增索引预算为 256 MiB，超限保留上次成功结果。该预算不是应用总磁盘占用上限。
- **移动前核对**：普通移动在选择目标目录后，展示文件数量、源目录和目标目录，再确认执行。明确提示“扫描不改原文件，整理前预览确认”。

扫描会写入应用自己的本地索引，不修改被扫描文件。文件、索引与操作日志留在本机。数据库会自动升级至 schema v5，升级后不支持直接使用 v0.4.0 读取新数据库。

已有用户可通过应用内检查更新安装；首次安装请选择 macOS `.dmg` 或 Windows x64 `-setup.exe` / `.msi`。应用内更新产物附带 updater 签名；平台代码签名、公证与完整 Windows 真机回归仍待完成。
