Luma v0.5.0 带来磁盘管家与 Agent 会话两个整机视角的新能力。

## 磁盘管家 I~V：找到整台电脑上可以删的内容

- **清理中心**：无需先扫描目录，统计系统与应用缓存、日志与崩溃报告、浏览器缓存、包管理器缓存（npm、pnpm、pip、uv）、开发工具缓存、安装镜像、超期下载与废纸篓；每类标注风险等级与判定依据，展开确认后清理。
- **项目瘦身**：按项目识别可重建产物（`node_modules`、`target`、`dist` 等），7 天内活跃项目自动保护，git 跟踪的产物不参与清理。
- **应用残留清理**（macOS）：找出已卸载应用的数据残留，按 bundle identifier 反查在用应用，共享容器与个人数据默认保留。
- **模拟器设备清理**（macOS）：仅清理系统明确标记为不可用的 Xcode 模拟器设备。
- **二进制瘦身**（macOS / Apple Silicon）：为通用版应用剥离无用 Intel 切片，全程在副本上完成，校验通过后才替换。
- **系统维护与状态卡片**：QuickLook 缓存刷新、DNS 刷新，以及托盘可联动的 CPU / 内存 / 电池快照。
- **白名单保护与清理历史**：受保护路径不出现在建议中、执行不触碰；每次清理记录状态与摘要，可追溯。

Windows 端提供基础清理中心；应用残留清理的 Windows 版本仍在推进，其余高级清理为 macOS 专属。

## Agent 会话：查看与管理本机 AI Agent 的会话

- **一眼看清**：自动发现本机 Claude Code、Codex、Gemini CLI 的本地会话，按项目或时间分组，显示标题、最近消息预览、最近活跃时间与占用大小。
- **多维筛选**：按 Agent 应用筛选（含各应用会话计数），按标题、目录、首末消息或会话 ID 搜索。
- **批量清理**：支持全局全选与按项目整组全选，确认后连同会话附属数据（子代理记录、文件历史等）一起移入废纸篓；单条删除同样走废纸篓。
- **可恢复**：删除绝不永久，可从系统废纸篓找回；每条会话提供复制恢复命令（如 `claude --resume <id>`）。
- **轻量只读**：仅读取转录头尾元数据，不解析正文入库，全部计算在本机完成。

方案与数据源见 [Agent 会话工作包](../agent-sessions.md)。

## 安全边界不变

与既有版本一致：删除只经废纸篓、绝不永久删除；写操作显式确认、执行前复核、白名单 fail-closed、操作全程留痕。扫描不修改被扫描文件，会话发现只读不写。

## 升级说明

已有用户可通过应用内检查更新安装；首次安装请选择 macOS `.dmg` 或 Windows x64 `-setup.exe` / `.msi`。本地数据库自动兼容升级，扫描索引与撤销记录保留；平台代码签名、公证与完整 Windows 真机回归仍待完成。
