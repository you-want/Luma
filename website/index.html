Luma — Local insight for your digital world.

你的电脑里装着数年的文件，却没有一张地图。Luma 扫描你指定的目录，呈现空间分类、重复文件候选、开发项目与历史变化，并支持按名称、大小、时间检索与批量选择、导出清单。它不修改任何原文件，所有分析都留在这台电脑。

光
两件事，做扎实

先看清，
再理解。

Luma 不急着做一个无所不知的助手。它的第一双眼睛是扫描器，把文件系统看清楚；第二个大脑才是理解，让这些文件真正对你有意义。

一

扫描 · 第一双眼睛

The Scanner

选择一个目录，Luma 在后台递归遍历，统计总大小、文件数与目录数，按图片、视频、文档、代码、压缩包等类别聚合占用。扫描过程实时显示进度，随时可以取消。单个文件出错不会中断整场扫描。

实时进度 · 可取消 · 容错
二

理解 · 第二个大脑

The Understanding

扫描结果落进本地 SQLite，重启后依然在。Luma 把零散的文件整理成可查询的空间地图：按名称、分类、大小、修改时间检索并分页排序，识别开发项目，对比同一目录最近三次扫描的容量与分类变化，还能跨页批量选择、复制路径或导出清单。

本地索引 · 检索过滤 · 项目识别 · 历史对比 · 批量导出
透明的发现，而非武断的删除

帮你看见，
被忽略的角落。

每一条发现都告诉你命中数量、总大小和判定依据，并留一个查看明细的入口。Luma 只报告，不替你做删除的决定。

巨

大文件

默认高于 1 GiB 的文件，阈值可在界面调整。哪些东西悄悄占了最多的地方，一目了然。

久

长期未整理

超过 180 天未修改的文件，并说明「修改时间不等于最近使用」，让你自己判断去留。

冗

开发体积

识别 node_modules、target、dist 这类常见的开发产物目录，只提示，不建议自动清理。

包

压缩与安装包

按扩展名聚合压缩包与安装包，提示这里可能是一片值得复查的可释放空间。

同

重复文件候选

由你主动发起后，Luma 才读取候选文件内容并在本机计算 BLAKE3 哈希，确认内容完全相同的文件组。

变

项目与历史

识别常见开发项目，并比较同一目录最近三次扫描，查看总容量、文件数和分类变化。

找得到，才用得上

检索与批量，
都在本地索引上。

扫描建立的本地索引不只是用来看的。你可以在其中检索、筛选，选中一批文件，把它们的路径导出——全部只读，不碰原文件。

检

检索 · 在索引里找

Search & Filter

按文件名或路径搜索已索引的文件，并叠加分类、扩展名、大小范围、修改时间等条件筛选。结果分页返回、可排序，也能直接在文件管理器中定位。检索只针对当前扫描快照，不触碰未索引的目录，也不读取文件内容。

名称/路径 · 多条件筛选 · 分页排序
选

批量 · 选中后导出

Bulk Selection

跨分页勾选文件，或一键选中全部筛选结果，界面实时显示已选数量。首版只提供非破坏性操作：复制路径列表到剪贴板、导出清单为 CSV——交给你自己的脚本或表格去处理。Luma 不移动、不删除任何文件。

Luma 的理解之道

从文件，
到行动。

真正的价值不在「扫描」—— 扫描谁都会。Luma 想走的是一条更长的路：先看见，再理解，然后记住，最后在你确认下行动。

  1. 见

    Scan

    遍历目录，读取元数据，画出空间全貌。

  2. 识

    Understand

    分类、识别开发项目、确认重复候选并呈现历史变化。

  3. 记

    Remember

    把稳定的元数据沉淀为可查询、可恢复的本地记忆。

  4. 行

    Act

    在你明确确认后，才归档或整理 —— 永远由你做主。

隐私是地基，不是选项

你的文件，
始终只关你的事。

  • 读
    只读、不改文件普通扫描只读取路径和元数据；只有你主动查找重复时才读取候选文件内容。Luma 不修改、移动或删除任何原文件。
  • 本
    数据不出本机路径与索引只保存在本地数据库，不上传、不发往远端、不写进联网日志。
  • 界
    不越界扫描默认不跟随符号链接，避免循环遍历，也不擅自跨越到其他挂载点。
守

你选择哪个目录，Luma 就只看哪个目录。理解你的数字世界，不等于把它交出去。

原生的分量

为桌面而生，
快而克制。

Luma 用原生技术栈构建：繁重的遍历交给 Rust 在后台完成，界面保持轻盈流畅，安装包也不臃肿。

Rust Scanner Core

文件遍历与聚合在 Rust 后台阻塞任务中进行，进度节流上报，不占用界面线程，也不把整份文件清单一次性搬进内存。

Tauri Native Shell

基于 Tauri 2 打包为原生桌面应用，体积小、启动快，权限受控 —— 每一项能力都对应明确的系统授权。

React Interface

React 19 + TypeScript 构建界面，内置简体中文与英文并跟随系统语言，跟随系统的浅色与深色主题，键盘可操作，窄窗口下也不会横向溢出。

诚实的进度

一步一步，
把地基打牢。

Luma 还年轻。v0.2.0 先把「看见、复查、比较」做到可靠，再继续探索更深的本地理解能力。

  1. 扫描原型Milestone 1

    选目录、看进度、可取消

    选择目录后看到实时的扫描进度与摘要，随时可以取消，坏文件不影响整体结果。

  2. 可恢复Milestone 2

    SQLite 索引与重启恢复

    扫描结果落盘为本地索引，重启后仍能查看最近一次成功扫描的完整结果页。

  3. 可用版Milestone 3

    重复候选、项目识别与历史对比

    在透明发现之上增加内容重复确认、开发项目识别和同目录历史比较，并打包为可安装的内部预览版。

  4. 检索与多语言Milestone 4

    索引检索、批量导出与中英文界面 v0.2.0

    本版已支持按名称、分类、大小、时间检索与分页排序；跨页批量选择并复制路径或导出清单（非破坏性，不移动删除）；界面内置简体中文与英文，跟随系统语言并可手动切换。应用会检查经过签名的 GitHub Release 更新，由你确认后下载、安装并重启。Windows 11 x64 真机安装、扫描和更新烟测仍待验收。

  5. 远景Beyond

    语义层与本地 AI 助手

    在数据可靠、持久稳定之后，再让模型基于结构化的本地信息回答问题，而非直接读取整个文件系统。
