Luma 帮助你管理堆积在桌面、下载目录和其他文件夹中的资料。从一个选定的目录开始，查看空间分布、查找文件，在同一工作区中预览和管理文件，再按规则生成整理清单。文件、扫描索引和操作日志保存在本机，不上传。

磁盘管家把「看清」扩展为整台电脑的视角：**看清占用 → 找到可删 → 安全清理**——清理系统缓存、开发产物与已卸载应用的残留，全程只经废纸篓、白名单保护、可解释可追溯。

支持 macOS 和 Windows，应用界面提供简体中文与英文。

已有用户可在应用内检查更新，确认后下载、安装并重启。应用启动时也会检查新版本，不会自动强制安装。

macOS 与 Windows 安装包均已发布；Windows 完整真机验收仍在完善。安装包暂未启用 Apple / Windows 平台代码签名与 macOS 公证，首次打开会被系统安全机制拦截一次，按下方步骤放行即可。应用内更新使用独立的签名校验。

### 首次安装提示

- **macOS**：打开 DMG，将 Luma 拖入「应用程序」后首次启动，若提示「无法验证开发者」或「无法检查是否包含恶意软件」，先点「完成」，然后打开 **系统设置 → 隐私与安全性**，在「安全性」区域找到关于 Luma 的提示，点 **「仍要打开」** 并验证密码或 Touch ID。macOS 13 及更早版本也可在应用图标上右键选「打开」放行。放行一次后即可正常启动，不会重复拦截。
- **Windows**：首次运行安装程序时，若 SmartScreen 提示「Windows 已保护你的电脑」，点 **「更多信息」→「仍要运行」**；浏览器提示下载风险时，选择保留文件即可。

熟悉终端的 macOS 用户也可以在安装后执行 `xattr -cr /Applications/Luma.app` 移除隔离标记。

## 主要功能

### 看清空间与文件

- **空间分析**：按文件类型查看占用分布，找出大文件，并查看长期未修改、开发构建内容、压缩包等复查线索。
- **本地搜索**：在当前扫描结果中按名称、路径、类型、大小和时间筛选，支持批量选择、复制路径与导出 CSV 清单。
- **重复文件查找**：主动查找后，通过内容哈希确认重复组，辅助判断重复占用；不会自动删除文件。
- **项目与历史**：识别常见开发项目，对比同一目录不同扫描时的容量、文件数量与分类变化。

### 预览、管理与整理

- **统一工作区**：在同一目录下切换空间分析与文件管理，浏览目录、排序文件，预览图片、文本和 PDF 首页。
- **文件操作**：支持重命名、复制、移动和移至废纸篓，可在系统文件管理器中定位文件。
- **规则整理**：提供桌面与下载分类方案，也可按文件类型、修改日期、扩展名或文件名关键词归类。
- **整理预览**：执行前查看原路径、目标路径与分类依据，排除不需要移动的文件，调整分类名称和单个文件去向。同名冲突可跳过或自动编号，不覆盖已有目标。
- **持久化撤销**：重命名、移动和规则整理记录在本地，重启后仍可撤销；复制和移至废纸篓不提供应用内撤销。

### 托盘：随时看一眼系统状态

Luma 常驻系统托盘，菜单可显示实时的 CPU 与内存占用（悬停托盘图标可见提示），开关默认**关闭**——在托盘菜单或「磁盘管家 → 系统状态」中显式开启后才会采样，重启后保留选择。关闭状态下 Luma 不做任何性能采样。

### 管理 Luma 的本地占用

「本地存储」可查看扫描索引与日志占用、回收空闲空间，或在确认后清理扫描索引。清理不会修改原文件，撤销记录也会保留。

Luma 仅保留最近一次成功扫描的完整文件索引，历史扫描保留统计摘要。索引保留策略、扫描容量预算与清理方式见[本地存储说明](docs/local-storage.md)。

### Agent 会话：查看与管理本机 AI Agent 的会话

「会话」页签自动发现本机 Claude Code、Codex 与 Gemini CLI 的本地会话记录：按项目或时间分组浏览，按 Agent 应用筛选，按标题、目录、首末消息或会话 ID 搜索。支持全局全选与按项目整组全选，确认后与会话附属数据一起移入废纸篓，可随时找回；每条会话附复制恢复命令。发现过程只读转录元数据，不解析正文入库，方案见[Agent 会话工作包](docs/agent-sessions.md)。

### 磁盘管家：找到整台电脑上可以删的内容

「磁盘管家」页签无需先扫描目录，直接统计这台电脑上常见的可清理位置：系统与应用缓存、日志与崩溃报告、浏览器缓存、包管理器缓存（npm、pnpm、pip、uv）、开发工具缓存、桌面与下载目录里的安装镜像、超期未动的下载文件和废纸篓。

每个类别标注风险等级与判定依据，展开即可勾选具体内容，确认后**全部移入系统废纸篓**——绝不永久删除，废纸篓本身也只统计、不清空。「受保护路径」白名单中的位置不会出现在建议里，也不会被清理触碰。安全机制按 Luma 的既有红线实现，方案见[磁盘管家工作包](docs/disk-cleaner.md)。

在基础清理之上，磁盘管家还提供：

- **项目瘦身**：按项目识别可重建的开发产物（`node_modules`、`target`、`dist` 等），7 天内活跃的项目自动保护，被 git 跟踪的产物不参与清理。
- **应用残留清理**（macOS）：找出已卸载应用留下的数据残留，按 bundle identifier 反查在用应用，共享容器与个人数据默认保留。
- **模拟器设备清理**（macOS）：识别系统明确标记为不可用的 Xcode 模拟器设备，在用中的设备永远不会成为候选。
- **通用二进制瘦身**（macOS / Apple Silicon）：为通用版应用剥离无用的 Intel 切片（约占体积一半），全程在副本上操作，原应用毫发无损。
- **系统维护与状态卡片**：QuickLook 缓存刷新、DNS 刷新（走系统授权窗口），以及 CPU / 内存 / 电池的实时快照。
- **清理历史**：最近的清理操作记录，含状态、摘要与时间，全部操作可追溯。

Windows 端当前提供基础清理中心（缓存、日志、包管理器、安装镜像等）；应用残留清理的 Windows 版本仍在推进，其余高级清理功能为 macOS 专属。

## 开始整理

1. **选择并扫描目录**：从桌面、下载目录或其他文件夹开始。扫描完成后，查看空间分析或进入文件管理。
2. **生成整理方案**：点击「整理」，选择规则、源目录和目标目录。默认只整理当前层的散文件，保留已有子文件夹与隐藏文件。
3. **预览并调整**：核对分类与目标路径，排除文件、调整去向，并处理同名冲突。修改方案后重新生成预览。
4. **确认后移动**：执行完成后查看结果与失败明细，需要恢复时使用「撤销」。

详细操作与边界见[文件夹整理指南](docs/folder-organizer.md)。当前分类依据文件名、类型和修改时间，不分析文档语义；Luma 不会在后台自动整理目录。

## 隐私与操作边界

**扫描不改原文件，整理前预览确认；清理只经废纸篓，永不永久删除。**

普通扫描读取路径、名称、大小和修改时间等元数据，不修改被扫描的文件；扫描结果会写入 Luma 自己的本地索引，占用一定磁盘空间。重复检测和内容预览由你主动触发，相关内容只在本机读取与处理。

文件修改均由你主动提交。普通移动在选择目标后再次核对数量与路径；规则整理先预览再确认；磁盘管家清理全程只经系统废纸篓，执行前逐项复核路径、大小与白名单；废纸篓本身只统计不清空。重命名通过回车或勾号保存，复制在系统目录选择框确认目标后执行，撤销点击后直接执行。

Luma 会保护系统关键路径，在执行前复核文件状态，并拒绝覆盖同名目标。文件已变化、路径冲突或权限不足时，操作可能失败；撤销也受原路径和文件状态约束。“大文件”“长期未修改”等线索仅供复查，不代表文件可以安全删除。

更新检查与安装包下载会连接 GitHub Releases，该过程不上传文件内容、扫描索引或操作日志。

## 开源与开发

Luma 基于 **Tauri 2、Rust、React、TypeScript 与 SQLite** 构建，采用 [MIT 许可证](LICENSE)。

开发前需准备 Node.js 22、pnpm 10、Rust stable 和对应平台的 [Tauri 系统依赖](https://v2.tauri.app/start/prerequisites/)。

```bash
pnpm install --frozen-lockfile
pnpm tauri dev
```
