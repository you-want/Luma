Luma 帮助你管理堆积在桌面、下载目录和其他文件夹中的资料。从一个选定的目录开始，查看空间分布、查找文件，在同一工作区中预览和管理文件，再按规则生成整理清单。文件、扫描索引和操作日志保存在本机，不上传。

支持 macOS 和 Windows，应用界面提供简体中文与英文。

## 主要功能

### 看清空间与文件

- **空间分析**：按文件类型查看占用分布，找出大文件，并查看长期未修改、开发构建内容、压缩包等复查线索。
- **本地搜索**：在当前扫描结果中按名称、路径、类型、大小和时间筛选，支持批量选择、复制路径与导出 CSV 清单。
- **重复文件查找**：主动查找后，通过内容哈希确认重复组，辅助判断重复占用；不会自动删除文件。
- **项目与历史**：识别常见开发项目，对比同一目录不同扫描时的容量、文件数量与分类变化。

### 预览、管理与整理

- **统一工作区**：在同一目录下切换空间分析与文件管理，浏览目录、排序文件，预览图片、文本和 PDF 首页。
- **文件操作**：支持重命名、复制、移动和移至废纸篓，可在系统文件管理器中定位文件。
- **规则整理**：提供桌面与下载分类方案，也可按文件类型、修改日期、扩展名或文件名关键词归类。
- **整理预览**：执行前查看原路径、目标路径与分类依据，排除不需要移动的文件，调整分类名称和单个文件去向。同名冲突可跳过或自动编号，不覆盖已有目标。
- **持久化撤销**：重命名、移动和规则整理记录在本地，重启后仍可撤销；复制和移至废纸篓不提供应用内撤销。

### 管理 Luma 的本地占用

「本地存储」可查看扫描索引与日志占用、回收空闲空间，或在确认后清理扫描索引。清理不会修改原文件，撤销记录也会保留。

Luma 仅保留最近一次成功扫描的完整文件索引，历史扫描保留统计摘要。索引保留策略、扫描容量预算与清理方式见[本地存储说明](docs/local-storage.md)。

## 开始整理

1. **选择并扫描目录**：从桌面、下载目录或其他文件夹开始。扫描完成后，查看空间分析或进入文件管理。
2. **生成整理方案**：点击「整理」，选择规则、源目录和目标目录。默认只整理当前层的散文件，保留已有子文件夹与隐藏文件。
3. **预览并调整**：核对分类与目标路径，排除文件、调整去向，并处理同名冲突。修改方案后重新生成预览。
4. **确认后移动**：执行完成后查看结果与失败明细，需要恢复时使用「撤销」。

详细操作与边界见[文件夹整理指南](docs/folder-organizer.md)。当前分类依据文件名、类型和修改时间，不分析文档语义；Luma 不会在后台自动整理目录。

## 隐私与操作边界

**扫描不改原文件，整理前预览确认。**

普通扫描读取路径、名称、大小和修改时间等元数据，不修改被扫描的文件；扫描结果会写入 Luma 自己的本地索引，占用一定磁盘空间。重复检测和内容预览由你主动触发，相关内容只在本机读取与处理。

文件修改均由你主动提交。普通移动在选择目标后再次核对数量与路径；规则整理先预览再确认；移至废纸篓需弹窗确认。重命名通过回车或勾号保存，复制在系统目录选择框确认目标后执行，撤销点击后直接执行。

Luma 会保护系统关键路径，在执行前复核文件状态，并拒绝覆盖同名目标。文件已变化、路径冲突或权限不足时，操作可能失败；撤销也受原路径和文件状态约束。“大文件”“长期未修改”等线索仅供复查，不代表文件可以安全删除。

更新检查与安装包下载会连接 GitHub Releases，该过程不上传文件内容、扫描索引或操作日志。

## 开源与开发

Luma 基于 **Tauri 2、Rust、React、TypeScript 与 SQLite** 构建，采用 [MIT 许可证](LICENSE)。

开发前需准备 Node.js 22、pnpm 10、Rust stable 和对应平台的 [Tauri 系统依赖](https://v2.tauri.app/start/prerequisites/)。

```bash
pnpm install --frozen-lockfile
pnpm tauri dev
```
